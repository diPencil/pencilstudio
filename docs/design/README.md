# Design Directory — Visual References

This folder holds design-side assets for the PENCIL Studio design system:
screenshots, layout references, and future design decision notes.

The normative design documentation lives in
[../DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md) — tokens, form-controls contract,
accessibility, RTL rules. This folder is supporting material only; nothing here
overrides the tokens defined in [`app/globals.css`](../../app/globals.css).
